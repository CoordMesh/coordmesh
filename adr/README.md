# Architecture Decision Records

ADRs capture significant architectural decisions and their context. Use one file per decision, named `NNNN-short-title.md`. Suggested sections: Status, Context, Decision, Consequences, Alternatives, Evidence, and Review history.

Statuses: **Proposed** (under review), **Accepted**, **Rejected**, **Superseded**, or **Withdrawn**. Proposed ADRs are not project commitments. Accepted decisions should be changed through a new ADR that explains the replacement; do not silently edit history.
